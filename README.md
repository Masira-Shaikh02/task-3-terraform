# Task 3 - Terraform with Docker

## Overview

This project demonstrates Infrastructure as Code (IaC) using Terraform to create and manage an Nginx Docker container.

## Technologies Used

- Terraform
- Docker
- Nginx
- Ubuntu / WSL

## What I Implemented

- Configured the Docker provider in Terraform
- Downloaded the Nginx Docker image using Terraform
- Created an Nginx Docker container using Terraform
- Configured port mapping from host port 8081 to container port 80
- Used Terraform commands to manage the infrastructure

## Terraform Commands Used

```bash
terraform init
terraform validate
terraform plan
terraform apply
terraform show
